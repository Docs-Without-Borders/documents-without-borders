## How to Transfer to GitHub Pages (2 minutes, no coding)

**STEP 1: Create repo**
1. Go to github.com → New repository
2. Repository name: `documents-without-borders`
3. Make it Public → Create repository

**STEP 2: Upload files**
1. On your new repo page, click "Add file" → "Upload files"
2. Drag and drop these 3 files from the zip:
   - index.html
   - dwb_globe_logo_cutout.png
   - README.md
3. Scroll down → Commit changes → Commit directly to main branch

**STEP 3: Turn on website**
1. Go to Settings → Pages (left sidebar)
2. Under Build and deployment:
   - Source: Deploy from a branch
   - Branch: main → / (root) → Save
3. Wait 60 seconds, refresh, your site will be live at:
   https://YOURUSERNAME.github.io/documents-without-borders/

**STEP 4 (Optional): Custom domain**
If you own documentswithoutborders.global:
- Settings → Pages → Custom domain → type it → Save
- Add the CNAME records GitHub shows you at your domain registrar

**Local test:** Double-click index.html on your computer - it works offline, no server needed.
