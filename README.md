## Deploy
1. Upload this zip to GitHub repo DWB-GLOBAL-SITE
2. Connect repo to Netlify
3. Add custom domain documentswithoutborders.org
4. In IONOS DNS: Delete A + AAAA records, keep MX and TXT, add A record @ -> 75.2.60.5 and CNAME www -> your-netlify-site.netlify.app
